# ☕ Altis Café: Real-World Sales & Operations Intelligence

An interactive web-based data analytics dashboard built to optimize menu profitability, transaction trends, and inventory management for hospitality businesses using real-world point-of-sale data.

## 🚀 About the Project
Physical retail and cafe businesses often struggle to identify which menu items drive true profit versus which ones tie up inventory. This dashboard bridges raw transaction logs with strategic decision-making, giving store managers clear visibility into revenue drivers, popular payment methods, and operational stocking priorities.

## 🛠️ Built With
* **Python** (Pandas) - Real-time data ingestion, cleaning, and aggregation
* **Streamlit** - Web framework for interactive application deployment
* **Plotly Express** - Dynamic, responsive data visualizations

## 📊 Core Features
* **Live Data Ingestion:** Automatically fetches and processes real-world transactional datasets on load.
* **Interactive Filtering:** Filter metrics and charts dynamically by specific menu items via the sidebar control panel.
* **Executive KPIs:** Instant overview of total revenue, transaction volume, and average order value (AOV).
* **Automated Insights:** Programmatically detects top-performing inventory items to guide supply chain preparation.
